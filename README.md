# 🌐 Traductor de Voz y Texto con Audio

Este proyecto permite traducir audio o texto a diferentes idiomas y escuchar la traducción generada mediante voz.

# Funcionalidades

- 🎤 Entrada por voz (usando Whisper de OpenAI)
- 📝 Entrada por texto
- 🌍 Traducción automática con Google Translate
- 🔊 Conversión a audio del texto traducido usando "gTTS"
- 💻 Interfaz con Gradio
